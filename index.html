关于试验数据库

这是怎样的数据库？

这是为 Mercury across Empires 研究设计的可扩展静态网站试验版。它使用真实、可点击来源的历史文献摘录，演示检索、分面筛选、跨语言关键词关联、阅读和导出。

数据边界：这些短文并非完整档案 OCR。本站没有下载、复制或展示档案馆受限影像；摘录来自公开电子转录，仍需与原书影像校核。英译摘要是研究性概述，不是逐字译文。

资料从哪里来？

包含宋、明、清时期文献，晚清矿业交涉材料、19世纪英文地理著述，以及一条现代研究文献书目。每条记录保留出处、原文链接和核查状态。

史料中的数字、日期、技术与药性主张属于历史记载，不代表已被独立证实，也不构成实验或医疗建议。

怎么扩充自己的资料？

  1. 在 data/records.csv 追加一行，填写编号、馆藏、标题、时期、短摘录和原件网址。
  2. 运行 python scripts/import_csv.py 重建前端搜索数据。
  3. 将新的原始 PDF 与图片放进自己私人的 originals/ 文件夹，不上传至公开仓库。
  4. 日后可将扫描页、OCR、人工校订和页码放入单独的 pages 表，保持原记录 ID 不变。
