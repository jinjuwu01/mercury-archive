# Mercury across Empires — Digital Atlas

**水银跨帝国：互动历史地图 | 1570–1910**

Live site: https://jinjuwu01.github.io/mercury-archive/atlas/

## About this version

The GitHub Pages build is a self-contained bilingual interactive research prototype. It provides:

- An interactive schematic world map, a 1570–1910 time slider, nine place anchors and eight research connections.
- A five-stage composite story set around the documented 1613 Manila–Acapulco mercury connection.
- Explicit evidence grades: documented, contextual and hypothesis.
- Source cards, an evidence-filterable research table, and CSV/JSON exports.
- A methodological note explaining incomplete provenance and the limits of schematic routes.

**Important**: The source-supported 1613 trans-Pacific shipment does not prove that this specific cargo originated in Wanshan. Links on this map are not ship tracks or reconstructed inland routes.

The published prototype is intentionally packaged in `index.html`: its datasets are the `P` (places), `R` (connections), `S` (sources) and `T` (story) arrays. This is distinct from the modular local ZIP version, which stores editable JSON under `data/`. The atlas can export its published dataset using the "Sources & Data" tab.

## Continuing the research

Before entering a new event or relation, preserve its original citation, date, places, historical spelling, units of measurement and evidence grade. See [AI_WORKFLOW.md](AI_WORKFLOW.md) for an AI-assisted review workflow.
